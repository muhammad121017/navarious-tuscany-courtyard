Concept 01 • Specificity Hierarchy

CSS Specificity Showdown

(Inline > ID > Class > Element)

CSS Specificity is the algorithm browsers use to determine which property value applies when multiple conflicting declarations target the exact same element. Specificity values are weighted into four distinct columns: (Inline, ID, Class, Element).

Rule Selector Target Element Specificity Score Calculated Winner
.card-title Margherita Card Title (0, 1, 0) — 1 Class Lost (Overridden by ID)
#first-dish .card-title Margherita Card Title (1, 1, 0) — 1 ID + 1 Class WINNER Applied 
/* RULE A: General class selector (0, 1, 0) */
.card-title {
  color: #1A1A1A;
  font-size: 1.15rem;
}

/* RULE B: ID + Descendant Class (1, 1, 0) */
#first-dish .card-title {
  color: #111111; /* WINS: ID (1,0,0) outweighs Class (0,1,0) */
  font-weight: 700;
}

Computed color: #111111 (Deep Onyx) because #first-dish .card-title holds specificity (1,1,0), completely overpowering .card-title (0,1,0).

Concept 02 • The Cascade Algorithm

Cascade & Source Order Tie-Breaker

Equal Specificity Tie-Breaker

When two conflicting declarations share the exact same specificity score, the CSS Cascade resolves the tie through Source Order: the declaration appearing last in the stylesheet wins. 

/* DECLARATION 1: Specificity (0, 1, 0) */
.order-btn {
  background-color: #1A1A1A; /* Charcoal: Declared First */
}

/* DECLARATION 2: Specificity (0, 1, 0) */
.order-btn {
  background-color: #E2725B; /* Terracotta: DECLARED LAST -> WINS! */
  color: #FFFFFF;
}
Live Button Winner Inspection

Computed background: #E2725B (Terracotta). Even though both rules targeted .order-btn with identical weight (0,1,0), Declaration 2 was read last by the CSS engine.

Concept 04 • Box Model Physics

Vertical Margin Collapsing Proof

32px + 24px = 32px

In CSS, the top and bottom margins of adjoining block-level boxes in normal flow collapse into a single margin. The resulting gap is equal to the maximum of the margins, not their arithmetic sum!

Paragraph A (Lead Text) — margin-bottom: 32px;

"Nestled within the vibrant corridor of Kohsar Market, Tuscany Courtyard remains an uncompromising tribute..."

↑ Collapsed Margin Gap = Exactly 32px (MAX of 32px & 24px, NOT 56px!) ↓
Paragraph B (Sub Text) — margin-top: 24px;

"Beyond ingredients, our sunlit outdoor courtyard was designed as a living sanctuary of Mediterranean leisure..." 

/* PHYSICAL COLLAPSE CALCULATION IN NORMAL FLOW */
.heritage-lead-p {
  margin-bottom: 32px; /* Margin A */
}

.heritage-sub-p {
  margin-top: 24px;    /* Margin B */
}

/* COMPUTED DISTANCE = MAX(32px, 24px) = 32px */
